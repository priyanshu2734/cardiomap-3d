            About this page

            What is real and what is a teaching simplification.

            • The heart shape is real reference anatomy (a generic atlas model), not a scan of anyone. The three coronary tubes are drawn by CardioMap along the grooves where these arteries normally run; the source mesh has no labelled coronaries.
            • Blood cells, the plaque inside a narrowed artery and the clot in a full blockage are display only. The cells are coloured from the model's own flow numbers (speed from flow divided by the lumen area at that point); the plaque is a schematic sleeve, not a measured lesion. Block selected artery sets the second narrowing to 99%, where the model's flow is about zero apart from any collateral share.
            • The heartbeat is a simplified model. The chambers shrink as rigid shapes and, in systole, the ventricular walls also shorten toward the long axis and thicken. This wall motion is exaggerated so it is visible (a few millimetres, capped so the wall never reaches the drawn blood), and a territory weakened by a narrowing thickens less. Aorta, pulmonary artery, veins and coronary widths are schematic additions, and all motion is exaggerated for visibility.
            • The four valves and the blood moving through the chambers are schematic teaching visuals, not patient-specific. Valve timing follows the same pressure windows as the Wiggers chart, and the flow through each chamber is shaped by the same volume curve, but leaflet shape, particle paths and speeds are drawn by CardioMap. The source mesh has no drawn valve leaflets or blood. The atrial squeeze (about 15% of the filling) is a schematic addition. Only the superior vena cava is drawn as a venous inlet, the four pulmonary veins as the left-side inlets, and the lungs are not drawn. The heart walls turn translucent while Valves or Chamber blood is on so the inside can be seen; blue is oxygen-poor and red is oxygen-rich blood.
            • "Narrowing" in this project's dataset means at least 50% stenosis of a vessel. What it does in a real person depends on where, how long, collateral vessels and which artery dominates the lower wall.
            How this works

            Equations used by the heartbeat animation (φ is the position in the beat from 0 to 1).

            Beat period      T = 60 / HR = 60 / 72 = 0.833 s,   φ = (t mod T) / T
Phase            systole for 0 ≤ φ < 0.35,  diastole for 0.35 ≤ φ < 1
Ventricular squeeze s(φ):
  0 ≤ φ < 0.35      s = ½ (1 − cos(π φ / 0.35))          rises 0 → 1
  0.35 ≤ φ < 0.55   s = ½ (1 + cos(π (φ − 0.35) / 0.20)) falls 1 → 0
  otherwise          s = 0
Atrial squeeze a(φ) = sin(π (φ − 0.88) / 0.12) for 0.88 ≤ φ < 1, else 0
Ventricles: p' = P + (r·I + (l − r)·u uᵀ)(p − P)
  r = 1 − 0.12 s (across the long axis),  l = 1 − 0.07 s (along it),
  u = unit base-to-apex axis, P = pivot 25% of the way from base to apex
Atria:      p' = C + (1 − 0.05 a + 0.025 s)(p − C),  C = each atrium's centre

            Timing fractions are typical textbook values at 72 bpm, not measured. The coronary tubes move with the ventricles.

            Blood flow equations

            One artery at a time, steady state (the pulse is applied afterwards as a multiplier). The page can add a second example narrowing in series; each d is a percent diameter reduction at a fixed schematic position.

            Narrowing        rs = r0 (1 − d/100),   As = π rs²,   A0 = π r0²
Pressure drop    ΔP = Rv·Q + Rt·Q²                      (across the narrowing)
  viscous        Rv = 8 μ Ls / (π rs⁴)                   ∝ 1/rs⁴
  turbulent      Rt = Kt ρ / 2 · (1/As − 1/A0)²
Healthy part     Rp = 8 μ (L − Ls) / (π r0⁴)
Demand           Qd = Qrest · m      m = 1 at rest, 3.5 in exercise by default (set 1.0 to 4.0 in Flow conditions)
Small vessels    Rm widens (autoregulation) to hold Q = Qd, down to
                 Rmin = (Pa − Pv) / (4 Qrest) − Rp0      (healthy peak = 4 × resting flow at the REFERENCE Pa = 90 mmHg;
                 Rmin is fixed, so a different Pa, μ or Ls changes capacity but not the small vessels)
Capacity         Rt·Qcap² + (Rp + Rv + Rmin)·Qcap = Pa − Pv
Delivered flow   Q = min(Qd, Qcap),    flow % of demand = 100 Q / Qd
Flow reserve     peak capacity = Qcap / Qrest (healthy ≈ 4×)
                 reserve left  = (Qcap − Qd) / (Qcap,healthy − Qd)
State            Flow limiting if Q < Qd; Reserve reduced if reserve left < 50%; else Flow maintained
Beat pulse       Q(φ) = Q · f(φ),   f = (1 − k·s(φ)) / mean(1 − k·s),   s = ventricular squeeze above
                 k = 0.70 (LAD, LCX) or 0.40 (RCA): flow dips in systole, is highest in diastole, mean over a beat = 1
Particles        each carries a share w of the artery's blood volume, dw/dt = Q(φ) / V,
                 so speed along the tube v(u) = Q / (π r(u)²): faster in the narrowing (continuity)
Colour           d < 50% green · 50 to 69% amber · 70% and above red

            Constants loading…
            • Pressures, resistances and flows are round teaching values, not measurements of any person. Real arteries differ in size, length, branches, collateral vessels and where the narrowing sits.
            • Rest and exercise use the same driving pressure, the mean aortic pressure (default 90 mmHg; you can set 60 to 120 in Flow conditions; the venous side stays 5 mmHg). Narrowing length (5 to 30 mm) sets Ls, and hematocrit (25 to 60%) sets viscosity μ through a smooth teaching approximation. Heart rate and ejection fraction do not enter the flow numbers. This page can show one or two example narrowings in series, plus optional teaching dominance and collateral controls; the heart muscle squeezing on the small vessels is represented only through the beat pulse above.
            • The narrowing is drawn as a smooth taper; the resistance uses its narrowest radius over the chosen length (default 10 mm). With two long narrowings the drawn tapers can overlap, although the model still adds them in series without interaction.
            • A rest-versus-exercise gap is the point of the model: an artery can meet demand at rest with a narrowing that fails it in exercise, because the small vessels have only so much room to widen.
            • "Below 50% is not counted as a stenosis in this dataset": the dataset flags a vessel as narrowed from 50% upward. The colours here follow that rule and are not a clinical grading.
