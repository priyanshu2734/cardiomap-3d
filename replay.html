What makes a run traceable?

✓ Exact submitted inputs, as supplied

✓ CAD, LAD, LCX and RCA outputs

✓ SHA-256 hashes of model and code artifacts

✓ Python and dependency versions

✓ Schema fingerprint and UTC timestamp

How to interpret a replay
MATCH Tracked artifact hashes and output values match the saved run within a tiny numeric tolerance.
CHANGED A tracked artifact hash or output differs; inspect the manifest before interpreting the difference.
INCOMPLETE Some tracked files or environment metadata are unavailable, so reproducibility cannot be fully assessed.
Matching outputs and hashes only support technical traceability. They are not evidence that the model is clinically valid, well-calibrated for a person, or appropriate for care decisions.
