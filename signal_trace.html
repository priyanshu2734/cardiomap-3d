    How to read this

    Each bar is a SHAP value: how far one input moved the model's output away from its starting point. SHAP describes the fitted model, not cause and effect.

    This trace links patient inputs to model attribution and a typical coronary territory. It does not identify a lesion, infarct size or myocardium at risk.

    Decision support and educational use only; not a substitute for formal diagnostic imaging.
